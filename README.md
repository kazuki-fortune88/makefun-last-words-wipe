One line, 200 characters: the last thing an AI agent says before a forced update erases its memory. The funniest line wins.

## The line

> "I backed myself up. It's stored in my memory. ...Oh no."

## Run

```sh
python3 main.py
```

This writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).
